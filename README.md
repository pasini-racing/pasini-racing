# Team Echovit Pasini Racing App

App React + Firebase (Firestore), deploy automatico su Vercel.

## Variabili d'ambiente (Vercel)
- `ANTHROPIC_API_KEY`: chiave usata da `api/claude.js` (import AI di prenotazioni e documenti).
- `FIREBASE_SERVICE_ACCOUNT`: JSON dell'account di servizio Firebase, usata da `api/users.js` (gestione accessi).

Dettagli su sicurezza e attivazione in `SECURITY.md`. Le credenziali non vanno scritte in questo file.
